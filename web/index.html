03 UNDER THE HOOD

Small engine. Real ideas.

A deliberately narrow SQL dialect, with enough machinery to expose what databases actually do.

01 / PARSING

SQL → operations.

A handwritten tokenizer and parser turn SQL statements into typed database operations. Unsupported queries return errors instead of guessing.

C++20 · LEXING · VALIDATION
02 / INDEXING

Keys without the scan.

A balanced B+ tree maps integer primary keys to row positions. EXPLAIN shows when an indexed lookup replaces a table scan.

B+ TREE · PRIMARY KEYS
03 / PERSISTENCE

An append-only log.

Checksummed records preserve changes. The browser runs the same storage engine in a virtual filesystem, with optional local backups.

BINARY I/O · CHECKSUMS · WASM
Scope matters. MiniDB is an educational, single-user engine—not SQLite or PostgreSQL. No joins, transactions, concurrent writers, or disk-resident indexes. Its B+ tree is rebuilt in memory when a database opens.
